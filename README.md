# YouTube Karaoke – Chrome Extension

ปรับคีย์เพลงและตัดเสียงนักร้องจากวิดีโอ YouTube / YouTube Music แบบเรียลไทม์

## ติดตั้ง

1. เปิด `chrome://extensions`
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้
4. รีเฟรชแท็บ YouTube ที่เปิดอยู่

## การใช้งาน

คลิกไอคอนไมค์บนแถบเครื่องมือ

- **ปรับคีย์**: −12 ถึง +12 ครึ่งเสียง ความเร็วเพลงไม่เปลี่ยน
- **ปรับความเร็ว**: 0.5× – 2× โดยคีย์ไม่เปลี่ยน ใช้ระบบยืดเวลาเสียงของ Chrome เอง และใช้ร่วมกับการปรับคีย์ได้
- **ตัดเสียงนักร้อง**: เปิด/ปิด และปรับความแรงได้ 0–200%
  - 0–100% กำหนดว่าจะลดเสียงที่อยู่ตรงกลางลงมากแค่ไหน
  - 100–200% (แรงพิเศษ) ตัดเสียงร้องที่ไม่ได้อยู่ตรงกลางพอดี เสียง ซ/ส (ถึง 16 kHz) และเสียงก้องได้มากขึ้น แต่เครื่องดนตรีที่อยู่ค่อนไปทางกลางจะเบาลงด้วย

| คีย์ลัด | การทำงาน |
|---|---|
| `Alt+Shift+↑` | เพิ่มคีย์ครึ่งเสียง |
| `Alt+Shift+↓` | ลดคีย์ครึ่งเสียง |
| `Alt+Shift+V` | เปิด/ปิด ตัดเสียงร้อง |
| `Alt+Shift+L` | แสดง/ซ่อน เนื้อร้อง |
| (ยังไม่ได้ตั้ง) | เร่ง/ลดความเร็ว ครั้งละ 0.05× |

ตั้งหรือเปลี่ยนคีย์ลัดได้ที่ `chrome://extensions/shortcuts` (Chrome ให้ตั้งคีย์ลัดเริ่มต้นได้แค่ 4 ปุ่ม ปุ่มปรับความเร็วจึงต้องตั้งเอง)

ถ้าความเร็วไม่ใช่ 1× ส่วนขยายจะบังคับใช้ความเร็วที่ตั้งไว้แทนเมนูความเร็วของ YouTube ถ้าจะใช้เมนูของ YouTube ให้รีเซ็ตความเร็วในส่วนขยายเป็น 1× ก่อน

ไอคอนจะมีป้ายบอกสถานะ เช่น `+2` (ปรับคีย์) หรือ `V` (ตัดเสียงร้องอยู่) การตั้งค่าจะถูกจำไว้ข้ามวิดีโอ

### เนื้อร้อง (ใช้ได้แม้เพลงไม่มี CC)

เปิดสวิตช์ **เนื้อร้อง** ในป๊อปอัป หรือกด `Alt+Shift+L`

- **คำบรรยาย (CC) ของวิดีโอ:** ถ้าวิดีโอมีคำบรรยายที่คนทำไว้ จะใช้คำบรรยายนั้นก่อน โดยเลือกภาษาเดียวกับเสียงในเพลง ไม่ใช่คำแปล ถ้า YouTube ต้องใช้ token ส่วนขยายจะเปิด CC ใน player สั้น ๆ แล้วปิดคืน ถ้าไม่มีทั้งคำบรรยายที่คนทำและผลใน LRCLIB จะใช้คำบรรยายที่ YouTube สร้างอัตโนมัติแทน เลือกคำบรรยายภาษาอื่นได้ในรายการ "ค้นหาเอง" และปิด "ใช้คำบรรยาย (CC) ของวิดีโอก่อน" ได้ในป๊อปอัป
- ส่วนขยายจะอ่านชื่อวิดีโอและชื่อช่อง ตัดคำอย่าง "Official MV" หรือ "เนื้อเพลง" ออก แล้วค้นหาเนื้อร้องจาก [LRCLIB](https://lrclib.net) ฐานข้อมูลเนื้อร้องแบบเปิด เลือกผลที่มีเวลากำกับและความยาวใกล้กับวิดีโอที่สุด
- **แบบซิงก์**: แสดงบรรทัดปัจจุบันตัวใหญ่บนวิดีโอ มีแถบสีวิ่งตามเพลงแบบคาราโอเกะ และแสดงบรรทัดถัดไปไว้ด้านล่าง ช่วงดนตรีจะแสดง ♪ และนับถอยหลังก่อนบรรทัดถัดไป ถ้าเปลี่ยนความเร็วเพลง เนื้อร้องยังตรงจังหวะ
- **แผงเนื้อเต็ม** (ค่าเริ่มต้น): แสดงเนื้อร้องทั้งเพลง บรรทัดที่กำลังร้องจะเป็นตัวใหญ่ กดบรรทัดไหนวิดีโอจะข้ามไปตรงนั้น ลากหัวแผงเพื่อย้าย ลากขอบซ้าย ขวา หรือล่างเพื่อปรับขนาด ตัวอักษรใหญ่หรือเล็กตามขนาดแผง และจำตำแหน่งไว้ใช้ครั้งหน้า สลับเป็นแบบ "2 บรรทัด" ได้จากแผงหรือจากป๊อปอัป
- **ซิงก์เอง** (สำหรับเนื้อร้องที่ไม่มีจังหวะ): กด ⏱ ซิงก์เอง เล่นเพลง แล้วกด "บรรทัดถัดไป" หรือคลิกบรรทัดตอนที่เริ่มร้อง บรรทัดที่ไม่ได้กดจะถูกเติมเวลาให้อัตโนมัติ แล้วกด "เสร็จ" ระบบจะจำไว้แยกตามวิดีโอ ครั้งต่อไปจะไฮไลต์ตามบรรทัดได้เลย
- **การแสดงผล** (ตั้งได้ในป๊อปอัป ปรับแยกกันได้):
  - ตัวอักษรวิ่งตามเพลง: ถ้าปิด บรรทัดปัจจุบันจะเป็นสีไฮไลต์ทั้งบรรทัด
  - พื้นหลังดำของแผง: ถ้าปิด แผงจะโปร่งใส ตัวอักษรมีขอบดำ และปุ่มบนแผงจะขึ้นเฉพาะตอนชี้เมาส์
  - สีไฮไลต์และสีตัวอักษร: เลือกเองได้ มีภาพตัวอย่างและปุ่มกลับเป็นสีเริ่มต้น
- **เนื้อร้องช้าไปหรือเร็วไป** (มักเกิดกับ MV ที่มีช่วงเปิดเรื่อง): ใช้ปุ่มเลื่อนเวลาครั้งละ 0.5 วินาทีในป๊อปอัป หรือเอาเมาส์ไปชี้ที่เนื้อร้องบนวิดีโอ
- **ไม่ตรงเพลง**: เปิด "ค้นหาเอง" พิมพ์ชื่อเพลงและศิลปิน แล้วเลือกจากรายการ
- **ไม่มีในฐานข้อมูล** (เพลงไทยบางเพลง): เปิด "วางเนื้อร้องเอง" แล้ววางข้อความ ถ้าวางไฟล์ `.lrc` ที่มีเวลากำกับ จะซิงก์ให้อัตโนมัติ
- เพลงที่เลือกเอง เนื้อร้องที่วางเอง และค่าเลื่อนเวลา จะถูกจำไว้แยกตามวิดีโอ
- ใช้ได้ทั้งเพลงไทยและอังกฤษ และใช้ได้ในโหมดเต็มจอ ขนาดตัวอักษรปรับตามขนาดของ player และจะซ่อนเนื้อร้องระหว่างโฆษณา

ป๊อปอัปมีป้ายบอกสถานะ (✓ โหลดสำเร็จ / ✕ โหลดไม่สำเร็จ / กำลังโหลด) และแสดงเนื้อร้องทั้งเพลงในป๊อปอัปด้วย ถ้าเป็นเนื้อร้องแบบซิงก์ บรรทัดที่กำลังร้องจะถูกไฮไลต์ และกดบรรทัดไหนวิดีโอจะข้ามไปตรงนั้น ถ้าเอาเครื่องหมาย "แสดงบนวิดีโอด้วย" ออก จะดูเนื้อร้องในป๊อปอัปอย่างเดียวได้

**สิทธิ์ที่ขอ:** `storage` สำหรับเก็บการตั้งค่า, `scripting` และสิทธิ์เข้าถึง youtube.com สำหรับเชื่อมต่อแท็บ YouTube ที่เปิดค้างไว้ก่อนอัปเดตหรือรีโหลดส่วนขยายใหม่โดยไม่ต้องรีเฟรช และสิทธิ์เข้าถึง lrclib.net สำหรับค้นหาเนื้อร้อง

**ความเป็นส่วนตัว:** อ่านนโยบายฉบับเต็มได้ที่ [PRIVACY.md](PRIVACY.md)

**ความเป็นส่วนตัว:** เมื่อเปิดใช้เนื้อร้อง ชื่อวิดีโอและชื่อช่องจะถูกส่งไปค้นหาที่ lrclib.net ถ้าปิดสวิตช์ไว้ จะไม่มีการส่งข้อมูลใด ๆ ออกไป

### คิวเพลง

- **เพิ่มเพลงเข้าคิว:** คลิกขวาที่ลิงก์หรือรูปตัวอย่างวิดีโอบน YouTube แล้วเลือก **"เพิ่มเข้าคิวคาราโอเกะ"** หรือกด **＋ เพิ่มวิดีโอนี้** ในป๊อปอัป หรือวางลิงก์ (`watch?v=`, `youtu.be`, `shorts`, YouTube Music)
- เมื่อเพลงในหน้าดูวิดีโอจบ จะเปิดเพลงถัดไปในคิวในแท็บเดิมให้เอง ก่อนเพลงจบประมาณ 10 วินาทีจะขึ้นว่า "⏭ ถัดไป: …" และจะไม่ข้ามเพลงตอนโฆษณาจบ
- ในป๊อปอัปกด ▶ เพื่อเล่นเพลงนั้นทันที ↑↓ เพื่อเรียงลำดับ ✕ เพื่อลบ หรือ ⏭ เพื่อข้ามไปเพลงถัดไป และปิด "เล่นเพลงถัดไปอัตโนมัติ" ได้
- ไม่สามารถเพิ่มเพลงซ้ำในคิว ชื่อเพลงดึงจาก oEmbed ของ YouTube และข้อมูลคิวเก็บไว้ในเครื่องเท่านั้น

### ภาษา / Language

ป๊อปอัปและข้อความบนหน้า YouTube รองรับภาษาไทยและอังกฤษ ครั้งแรกจะใช้ภาษาตาม Chrome และสลับได้ด้วยปุ่ม **TH / EN** มุมขวาบนของป๊อปอัป ชื่อส่วนขยายและคำอธิบายคีย์ลัดในหน้า `chrome://extensions` จะใช้ภาษาตาม Chrome (`_locales/`) เสมอ

The popup and on-page messages support Thai and English. The first time, it follows Chrome's language. Switch with the **TH / EN** buttons in the popup's top-right corner. The extension name and shortcut descriptions on `chrome://extensions` always follow Chrome's language (`_locales/`).

To add a language, add a block to `STRINGS` in [i18n.js](i18n.js), a button in `popup.html`, and a folder under `_locales/`.

## หลักการทำงาน

เสียงของ `<video>` จะถูกส่งเข้า Web Audio API ไปยัง AudioWorklet (`karaoke-processor.js`) ซึ่งประมวลผลแบบ STFT (FFT 2048, overlap 8×)

- **ตัดเสียงร้อง**: ในแต่ละช่วงความถี่ระหว่าง 100 Hz – 8 kHz ถ้าช่องซ้ายและขวาเหมือนกัน (คือเสียงที่วางไว้ตรงกลาง ซึ่งมักเป็นเสียงร้อง) จะลดเสียงช่วงนั้นลง ส่วนเบส กลองเตะ และเครื่องดนตรีที่แพนไปซ้ายหรือขวาจะยังอยู่ และเสียงยังเป็นสเตอริโอ
- **ปรับคีย์**: ใช้ phase vocoder แบบ peak-locked (Laroche & Dolson) ซึ่งย้ายยอดสเปกตรัมพร้อมรักษาเฟส จึงฟังเป็นธรรมชาติกว่า vocoder แบบพื้นฐาน

ถ้าทุกค่ายังเป็นค่าเริ่มต้น ส่วนขยายจะไม่ยุ่งกับเสียงของ YouTube เลย เมื่อปรับค่ากลับเป็นค่าเริ่มต้น เสียงจะต่อตรงโดยไม่ผ่านตัวประมวลผล

## ข้อจำกัด

- การตัดเสียงร้องได้ผลดีกับเพลงสเตอริโอที่มิกซ์เสียงร้องไว้ตรงกลาง ถ้าเป็นเพลงโมโน เสียงทั้งหมดในช่วงความถี่นั้นจะหายไปด้วย
- เสียงก้องและคอรัสที่แพนกว้างอาจยังหลงเหลืออยู่ เครื่องดนตรีที่อยู่ตรงกลาง เช่น สแนร์ จะเบาลงด้วย
- เสียงช้ากว่าภาพประมาณ 43 ms ขณะเปิดเอฟเฟกต์ ซึ่งแทบไม่รู้สึก
- Chrome ไม่ยอมให้เล่นเสียงผ่าน Web Audio จนกว่าผู้ใช้จะโต้ตอบกับหน้าเว็บ ถ้าขึ้นข้อความ "คลิกที่หน้า YouTube" ให้คลิกที่หน้าเว็บหนึ่งครั้ง
