# YouTube Karaoke – Chrome Extension

ปรับคีย์เพลงและตัดเสียงนักร้องจากวิดีโอ YouTube / YouTube Music แบบเรียลไทม์

## ติดตั้ง

1. เปิด `chrome://extensions`
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้
4. รีเฟรชแท็บ YouTube ที่เปิดอยู่

## การใช้งาน

คลิกไอคอนไมค์บนแถบเครื่องมือ

- **ปรับคีย์**: −12 ถึง +12 ครึ่งเสียง ความเร็วเพลงไม่เปลี่ยน
- **ปรับความเร็ว**: 0.5× – 2× โดยคีย์ไม่เปลี่ยน ใช้ระบบยืดเวลาเสียงของ Chrome เอง และใช้ร่วมกับการปรับคีย์ได้
- **ตัดเสียงนักร้อง**: เปิด/ปิด และปรับความแรงได้ 0–200%
  - 0–100% กำหนดว่าจะลดเสียงที่อยู่ตรงกลางลงมากแค่ไหน
  - 100–200% (แรงพิเศษ) ตัดเสียงร้องที่ไม่ได้อยู่ตรงกลางพอดี เสียง ซ/ส (ถึง 16 kHz) และเสียงก้องได้มากขึ้น แต่เครื่องดนตรีที่อยู่ค่อนไปทางกลางจะเบาลงด้วย

| คีย์ลัด | การทำงาน |
|---|---|
| `Alt+Shift+↑` | เพิ่มคีย์ครึ่งเสียง |
| `Alt+Shift+↓` | ลดคีย์ครึ่งเสียง |
| `Alt+Shift+V` | เปิด/ปิด ตัดเสียงร้อง |
| (ยังไม่ได้ตั้ง) | เร่ง/ลดความเร็ว ครั้งละ 0.05× |

ตั้งหรือเปลี่ยนคีย์ลัดได้ที่ `chrome://extensions/shortcuts` (Chrome ให้ตั้งคีย์ลัดเริ่มต้นได้แค่ 4 ปุ่ม ปุ่มปรับความเร็วจึงต้องตั้งเอง)

ถ้าความเร็วไม่ใช่ 1× ส่วนขยายจะบังคับใช้ความเร็วที่ตั้งไว้แทนเมนูความเร็วของ YouTube ถ้าจะใช้เมนูของ YouTube ให้รีเซ็ตความเร็วในส่วนขยายเป็น 1× ก่อน

ไอคอนจะมีป้ายบอกสถานะ เช่น `+2` (ปรับคีย์) หรือ `V` (ตัดเสียงร้องอยู่) การตั้งค่าจะถูกจำไว้ข้ามวิดีโอ

### ภาษา / Language

ป๊อปอัปและข้อความบนหน้า YouTube รองรับภาษาไทยและอังกฤษ ครั้งแรกจะใช้ภาษาตาม Chrome และสลับได้ด้วยปุ่ม **TH / EN** มุมขวาบนของป๊อปอัป ชื่อส่วนขยายและคำอธิบายคีย์ลัดในหน้า `chrome://extensions` จะใช้ภาษาตาม Chrome (`_locales/`) เสมอ

The popup and on-page messages support Thai and English. The first time, it follows Chrome's language. Switch with the **TH / EN** buttons in the popup's top-right corner. The extension name and shortcut descriptions on `chrome://extensions` always follow Chrome's language (`_locales/`).

To add a language, add a block to `STRINGS` in [i18n.js](i18n.js), a button in `popup.html`, and a folder under `_locales/`.

## หลักการทำงาน

เสียงของ `<video>` จะถูกส่งเข้า Web Audio API ไปยัง AudioWorklet (`karaoke-processor.js`) ซึ่งประมวลผลแบบ STFT (FFT 2048, overlap 8×)

- **ตัดเสียงร้อง**: ในแต่ละช่วงความถี่ระหว่าง 100 Hz – 8 kHz ถ้าช่องซ้ายและขวาเหมือนกัน (คือเสียงที่วางไว้ตรงกลาง ซึ่งมักเป็นเสียงร้อง) จะลดเสียงช่วงนั้นลง ส่วนเบส กลองเตะ และเครื่องดนตรีที่แพนไปซ้ายหรือขวาจะยังอยู่ และเสียงยังเป็นสเตอริโอ
- **ปรับคีย์**: ใช้ phase vocoder แบบ peak-locked (Laroche & Dolson) ซึ่งย้ายยอดสเปกตรัมพร้อมรักษาเฟส จึงฟังเป็นธรรมชาติกว่า vocoder แบบพื้นฐาน

ถ้าทุกค่ายังเป็นค่าเริ่มต้น ส่วนขยายจะไม่ยุ่งกับเสียงของ YouTube เลย เมื่อปรับค่ากลับเป็นค่าเริ่มต้น เสียงจะต่อตรงโดยไม่ผ่านตัวประมวลผล

## ข้อจำกัด

- การตัดเสียงร้องได้ผลดีกับเพลงสเตอริโอที่มิกซ์เสียงร้องไว้ตรงกลาง ถ้าเป็นเพลงโมโน เสียงทั้งหมดในช่วงความถี่นั้นจะหายไปด้วย
- เสียงก้องและคอรัสที่แพนกว้างอาจยังหลงเหลืออยู่ เครื่องดนตรีที่อยู่ตรงกลาง เช่น สแนร์ จะเบาลงด้วย
- เสียงช้ากว่าภาพประมาณ 43 ms ขณะเปิดเอฟเฟกต์ ซึ่งแทบไม่รู้สึก
- Chrome ไม่ยอมให้เล่นเสียงผ่าน Web Audio จนกว่าผู้ใช้จะโต้ตอบกับหน้าเว็บ ถ้าขึ้นข้อความ "คลิกที่หน้า YouTube" ให้คลิกที่หน้าเว็บหนึ่งครั้ง
